# MGTU-JS-Project t


## Что умеет

- Загружает вопросы из JSON-файла — банк вопросов можно менять, не трогая код
- Проводит пользователя по вопросам и подсчитывает результат
- Показывает итоги на странице `results.html`
- Анимирует переходы между вопросами и появление результата (`animations.css`)

## Как устроено


|------|------|
| `index.html` | Главная страница и интерфейс квиза |
| `main.js` | Логика прохождения вопросов и подсчёта баллов |
| `questions.json` | Банк вопросов |
| `results.html` / `results.js` | Страница результатов и её логика |
| `animations.css` | Стили и анимации |
| `package.json` | Зависимости и скрипты запуска |
